>
> Bạn đang chuẩn bị clone một repository có thể khiến máy tính:
>
> - Tự nhiên muốn uống cà phê lúc 2 giờ sáng ☕
> - Tăng 200% khả năng mở Canva thay vì làm bài 📚
> - Phát hiện bạn đã đọc README nhưng vẫn bấm `git clone` 😄
> - Bị nhiễm **virus lười biếng** — loại virus khiến bạn chỉ muốn nằm im và không làm gì cả.
>
> **Đùa thôi!** Đây chỉ là lời trêu vui, không phải cảnh báo bảo mật thực tế. Tuy nhiên, bạn vẫn nên kiểm tra mã nguồn và chỉ chạy các file mà mình hiểu rõ. Đừng clone hoặc chạy phần mềm từ nguồn không đáng tin cậy trên máy quan trọng.
>
> ## Mục đích
>
> Công cụ hỗ trợ tạo tài liệu PDF từ mẫu có sẵn. Nếu bạn đang tìm một công cụ nguy hiểm, rất tiếc — repository này chỉ có Python và vài dòng code, chưa đủ sức hù dọa chiếc máy tính của bạn đâu 🐍
>
> ## Cách sử dụng
>
> 1. Đọc kỹ mã nguồn trước khi chạy.
> 2. Chuẩn bị dữ liệu đầu vào theo hướng dẫn trong thư mục `docs/Gen docs`.
> 3. Chạy công cụ trong môi trường an toàn nếu bạn chưa chắc chắn.
> 4. Nếu thấy máy tính tự mở Canva, hãy bình tĩnh — có thể đó chỉ là bạn tự bấm nhầm.
>
> ## Lời nhắn cuối
>
> Nếu bạn không muốn tải repository này xuống thì hãy đóng tab ngay bây giờ.
> Nếu vẫn tiếp tục clone, chúng tôi xin chúc mừng: bạn đã chính thức bị đánh bại bởi sự tò mò 😎
